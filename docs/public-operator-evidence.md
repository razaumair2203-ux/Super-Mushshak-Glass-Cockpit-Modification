# Independent Public Glass-Cockpit and Operator Evidence

This page is **independent corroboration and programme context**, not a substitute for the authentic project photographs and period engineering evidence in this repository.

The evidence rule is simple:

> **A photograph establishes only what is visible; an exact avionics configuration is asserted only when a credible source identifies it.**

## Broader historical operator record

APP's 2016–2017 reporting independently states that Super Mushshak was already in service in **Saudi Arabia, Oman, Iran and South Africa** when the Nigeria / Türkiye / Azerbaijan export sequence was being reported. A separate APP Qatar report also referenced Syria.

Times Aerospace's 2017 programme history likewise listed Iran, Oman, Saudi Arabia and Syria among earlier users, with limited civil use in South Africa.

These are retained as **historical operator context**. This repository does not convert an old operator list into a claim of present-day fleet strength.

## Relation to the retrofit case study

The public record is important because it provides an independent line of evidence that the aircraft family subsequently appeared in export service with the same two glass-cockpit families represented in the retrofit archive:

- **Dynon** — independently reported on the Nigerian export fleet;
- **Garmin 950** — independently reported on Qatar and Türkiye;
- **Azerbaijan** — operator status is verified, but the cited configuration source does not identify the selected avionics suite.

This is **programme continuity evidence**, not a claim that the early prototype was reproduced unchanged and not a claim that any one engineer or prototype alone caused later export sales.

## Image-use rule

- Project photographs remain the primary evidence for work performed during the retrofit.
- Third-party photographs are source-linked context only.
- Third-party images are not mirrored into the repository unless their licence explicitly permits it and attribution is preserved.
- No external photograph is used to infer hidden avionics, wiring, configuration or test status.
- No synthetic aircraft, cockpit, equipment or test imagery is used.
